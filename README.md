## 🚀 Projects

### 🍅 TomatoFusion
**Explainable Hybrid Ensemble for Tomato Leaf Disease Classification · Undergraduate Thesis**

- Built an end-to-end deep learning system with model evaluation, Grad-CAM explainability, and web deployment.
- Evaluated **12 deep learning models and five hybrid ensembles** using **2,486 curated images**.
- Combined EfficientNetV2M, MobileNetV3Large, and DenseNet201, achieving **88.00% accuracy**, **0.8785 weighted F1**, and **0.9673 macro AUC**.

[💻 Repository](https://github.com/AfnanBinIslamNahin/TomatoFusion) · [🌐 Live Application](https://tomatofusion.onrender.com/#home)
